# Changelog

Notable user-facing and contributor-facing project changes are recorded here. The project does not yet have a tagged application release; entries remain under **Unreleased** until the first release.

## Unreleased

### Added

- Optional Cloudflare Workers AI heat-safety assistant and its server-side proxy.
- Collapsible, keyboard-accessible navigation.
- Topic-based documentation for architecture, forecasts, AI scope, interface, requirements, releases, licensing, and demonstrations.
- GitHub issue forms, a pull-request checklist, and a code of conduct.

### Changed

- Expanded the README and contribution guide to describe current behavior, setup, verification, deployment, and safety limits.

### Removed

- Removed stale manual exposure-timer documentation, styling, and script references; the current application has no manual timer.

## 2026-10-22 — Initial repository

- Added the static Central Visayas heat-index map, hourly forecast interface, heat-index categorization, and project pages.
